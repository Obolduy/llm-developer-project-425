# Удалённый доступ и VPN

Для работы вне офиса используется корпоративный VPN-клиент WireGuard.

## Как подключиться

1. Установите клиент WireGuard с официального сайта под свою ОС.
2. Заявку на конфиг присылайте на Help Desk с темой «VPN» — в течение рабочего дня придёт файл `.conf` и краткая инструкция по импорту.
3. После импорта конфига включите подключение в клиенте — статус должен смениться на «Активно» в течение нескольких секунд.

## Частые проблемы

- **Пишет ошибку авторизации** — конфиг мог устареть (перевыпускается раз в 90 дней). Закажите новый через Help Desk.
- **Подключение есть, но сервисы недоступны** — проверьте, что в настройках клиента включён пункт «Разрешить весь трафик через туннель». Если включён и всё равно не работает — заведите тикет с приложенным скриншотом статуса подключения.
- **VPN обрывается каждые несколько минут** — обычно это конфликт с другим VPN или локальным фаерволом. Отключите сторонние VPN-клиенты на время работы.

Доступ к внутренним сервисам (Git, вики, трекер задач) возможен только через VPN — из открытой сети они недоступны намеренно.
